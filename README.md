## About

I'm an engineer first and a founder second. I run **[savv.pro](https://savv.pro)** from Islamabad, where I lead a team of five building agentic SaaS and custom enterprise AI, and I still write a lot of the code.

Before that I spent two and a half years at **Maida.co** as Backend & DevOps Lead. I ran AI image-processing workloads on Kubernetes and kept high-traffic systems at 99.9% uptime.

> 🔒 Nearly all of my work is client and company code in private repos, so the green squares tell more of the story than the public repos do.
